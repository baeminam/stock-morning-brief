종합 점수 산정 방식
1. 기술적 점수 (0~100점) — 최근 120일 주가·거래량으로 계산한 지표를 각각 0~100점으로 환산한 뒤 가중합합니다.
  · RSI(14) — 가중치 {{ method.rsi_w }}: 30 이하 과매도는 반등 기대로 60점, 55 부근이 100점 만점, 70 이상은 단기 과열로 감점 (예: RSI 55 → 100점, RSI 75 → 45점)
  · MACD 히스토그램 — 가중치 {{ method.macd_w }}: 상승 신호(양수)일수록 고득점 (주가 대비 -1% → 0점, 0 → 50점, +1% 이상 → 100점)
  · 20일 이평선 괴리 — 가중치 {{ method.ma_w }}: 현재가가 20일선보다 높을수록 고득점 (-10% 이하 → 0점, 20일선과 같으면 50점, +10% 이상 → 100점)
  · 볼린저밴드 %B — 가중치 {{ method.bb_w }}: 밴드 중간~상단(55% 지점)이 100점, 하단 터치나 상단 돌파 등 극단으로 갈수록 감점
  · 거래량 배율 — 가중치 {{ method.vol_w }}: 20일 평균 대비 거래량이 많을수록 고득점 (0.5배 이하 → 0점, 1배 → 20점, 3배 이상 → 100점)
2. 기본적 점수 (0~100점)
  · IB 컨센서스 — 가중치 {{ method.ib_w }}: 애널리스트 평균 의견이 매수에 가까울수록 고득점 (강력매도 1.0 → 0점, 중립 3.0 → 50점, 강력매수 5.0 → 100점). 최근 90일 투자의견 상향 1건당 +5점, 하향 1건당 -5점 가감
  · 목표가 괴리 — 가중치 {{ method.gap_w }}: 평균 목표가가 현재가보다 높을수록(상승 여력) 고득점 (-20% 이하 → 0점, 현재가와 같으면 33점, +40% 이상 → 100점). 단, 목표가가 없는 종목은 중립 50점
  · 뉴스 감성 — 가중치 {{ method.news_w }}: 최근 뉴스 제목에서 긍정 키워드(상승·호재·목표가 상향 등)가 부정 키워드보다 많을수록 고득점. 뉴스가 없으면 중립 50점
  · 시장 모멘텀 — 가중치 {{ method.sector_w }}: 같은 시장 전체의 평균 20일 수익률이 높을수록 고득점 (-10% → 0점, +10% → 100점)
3. 종합 점수 = 기술적 점수 × {{ method.tech_ratio_pct }}% + 기본적 점수 × {{ method.fund_ratio_pct }}%
  ※ 데이터가 없는 항목은 중립값(50점)으로 처리되며, 종목 간 비교 가능하도록 모든 점수는 0~100으로 정규화됩니다.
4. 추천 순위 — 각 국가별 Top 10을 선정하며, 단기와 장기의 기준은 서로 다릅니다.
  · 단기 추천 (단기 점수 순): RSI(30) + MACD(25) + 20일 이평선 괴리(20) + 볼린저밴드(15) + 거래량 배율(10) — 당장의 매수세와 모멘텀을 봅니다. 예: 거래량이 평소의 2배로 늘며 MACD가 상승 전환한 종목이 고득점
  · 장기 추천 (장기 점수 순): 60일 이평선 대비 위치(40%) + 60일 수익률(40%) + 추세 전환(20%)으로, 모두 높을수록 고득점입니다. 예: 60일 수익률 -30% 이하 → 0점, 0% → 50점, +30% 이상 → 100점. 즉 이미 오른 종목일수록(추세 추종) 유리하며, 하락 중인 종목은 '싸다'는 이유만으로는 추천되지 않습니다
  ※ 카드 우측 상단 숫자가 그 섹션의 순위 기준 점수이며, 종합 점수는 카드 본문에 별도 표기됩니다.
